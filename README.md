# DropTheWish — GitHub 업로드용

## 폴더 구조
- `index.html` : 영어 페이지
- `jp/index.html` : 완전히 별도로 디자인된 일본어 페이지
- `favicon.svg` : 공용 파비콘

## 접속 주소
- 영어: `https://도메인/`
- 일본어: `https://도메인/jp/`

## GitHub 업로드
이 ZIP의 내용물을 저장소 최상단에 그대로 업로드하세요.
GitHub Pages는 저장소 Settings → Pages에서 배포할 브랜치를 선택하면 됩니다.

## 참고
현재 폼은 정적 페이지 데모 방식이라 제출 시 같은 페이지에서 완료 메시지만 표시됩니다.
실제 응모 내용을 저장하려면 Formspree, Google Apps Script, Supabase 등의 제출 엔드포인트 연결이 필요합니다.

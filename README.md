# DropTheWish

Official landing page for **DropTheWish**, a Late Checkout project.

## Files

- `index.html` — complete landing page, responsive styles, JavaScript, and Netlify form
- `favicon.svg` — browser favicon
- `og-image.jpg` — social sharing image

## Deploy

1. Upload all files to the root of the GitHub repository.
2. Commit the changes.
3. Netlify will redeploy automatically.
4. In Netlify, confirm that the form appears under **Forms → wishlist-entry**.
